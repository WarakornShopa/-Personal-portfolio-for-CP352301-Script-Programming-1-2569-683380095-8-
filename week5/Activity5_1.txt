-----กิจกรรมที่ 5.1: การประยุกต์ใช้ Dictionary และ Set ในชีวิตจริง-----

* คำชี้แจง: ให้นักเรียนช่วยกันยกตัวอย่างสถานการณ์หรือปัญหาในชีวิตจริงที่ Dictionary และ Set เหมาะสมจะถูกนำมาใช้เป็นโครงสร้างข้อมูล พร้อมอธิบายเหตุผลประกอบ
Answer --> ระบบลงทะเบียนเข้างานหรือเช็กชื่อผู้เข้าร่วมกิจกรรม เพราะสามารถใช้เก็บรายชื่อผู้เข้าร่วมโดยไม่ให้มีชื่อซ้ำกัน และสามารถตรวจสอบได้อย่างรวดเร็วว่าบุคคลนั้นลงทะเบียนแล้วหรือยัง

คำถามกระตุ้นความคิด (Prompts):
    1.) คุณจะนำ Dictionary ไปใช้ตรงไหนในเกมได้บ้าง? (เช่น ช่องเก็บของของผู้เล่น (Inventory), ค่าพลังของตัวละคร)
    Answer --> 
        - ค่าสถานะตัวละคร

        player = {
            "HP": 100,
            "MP": 50,
            "Level": 10
        }

        เหตุผล: เก็บข้อมูลแต่ละค่าสถานะไว้เป็นคู่ Key-Value ทำให้อ่านและแก้ไขค่าได้ง่าย

        - ช่องเก็บของ (Inventory)

        inventory = {
            "Potion": 10,
            "Sword": 1,
            "Arrow": 50
        }

        เหตุผล: ใช้ชื่อไอเท็มเป็น Key และจำนวนเป็น Value ทำให้ค้นหา เพิ่ม หรือลดจำนวนไอเท็มได้รวดเร็ว

    2.) Dictionary จะช่วยจัดเก็บข้อมูลสินค้าในร้านค้าออนไลน์ได้อย่างไร? (เช่น ข้อมูลรายละเอียดสินค้าโดยใช้อ้างอิงจากรหัสสินค้า/ID)
    Answer --> 
            products = {
                "P001": {
                "name": "Keyboard",
                "price": 890,
                "stock": 20
                }
            }

        เหตุผล: ใช้รหัสสินค้าเป็น Key เพื่อค้นหาสินค้าได้รวดเร็ว และเก็บรายละเอียดของสินค้าไว้ใน Value

    3.) Set จะมีประโยชน์อย่างไรในการจัดการสิทธิ์ของผู้ใช้ หรือการจัดการแท็ก? (เช่น บทบาทสิทธิ์ใช้งานที่ไม่ซ้ำกัน, แฮชแท็กที่ไม่ซ้ำกัน)
    Answer --> 
            - สิทธิ์ของผู้ใช้

            permissions = {"read", "write", "delete"}

            เหตุผล: สิทธิ์แต่ละอย่างไม่ควรซ้ำกัน และสามารถตรวจสอบได้อย่างรวดเร็วว่าผู้ใช้มีสิทธิ์นั้นหรือไม่

            - แฮชแท็ก

            hashtags = {"Python", "AI", "Programming"}

            เหตุผล: หากมีการเพิ่มแท็กเดิมเข้ามา Set จะไม่เก็บข้อมูลซ้ำ

    4.) นึกออกไหมว่ามีสถานการณ์ไหนบ้างที่เราต้องเช็กอย่างรวดเร็วว่า "มีข้อมูลนี้อยู่ในกลุ่มข้อมูลขนาดใหญ่หรือไม่" โดยไม่สนใจลำดับก่อนหลัง? (เช่น รายชื่อ IP Address ที่ถูกบล็อก, การนับจำนวนผู้เข้าชมเว็บที่ไม่นับคนซ้ำ)
    Answer --> 
            - รายชื่อ IP Address ที่ถูกบล็อก

            blocked_ip = {"192.168.1.1", "10.0.0.5"}

            เหตุผล: สามารถตรวจสอบได้อย่างรวดเร็วว่า IP ที่เข้ามาถูกบล็อกหรือไม่

            - การนับผู้เข้าชมเว็บไซต์แบบไม่นับคนซ้ำ

            visitors = {"User001", "User002", "User003"}

            เหตุผล: Set จะเก็บเฉพาะผู้เข้าชมที่ไม่ซ้ำกัน ทำให้รู้จำนวนผู้ใช้จริงได้ง่าย
